# buyer-v8: первая принятая живая генерация сравнения

После публикации buyer-v8 и бесплатной проверки конфигураций всех шести Workers пользователь отдельно согласовал **один** запрос с резервом до USD0.01, без повторов. Выполнен один английский вопрос сравнения прежней пары Apavi40plus. Остальные 49 записей плана нужны только существующему runner и не разрешены/не выполнены. Русский, латышский, другие магазины и старые 27/50 не проверялись.

## Технический результат

- HTTP200, `buyer-v8`, `providerUsed:true`, `conversational:true`.
- Нет `fallbackReason`, `validationReason`, ошибок чтения или автоматических флагов.
- Обе страницы товаров прочитаны и обе ссылки приложены; historical snapshot не использовался.
- Одна попытка провайдера, 0 неопределённых запросов и 0 повторов.
- Ответ занял **9364мс**. Это измерение одного запроса, не медиана и не обещание такой задержки для всех клиентов.
- Резерв **10000microUSD = USD0.01**. Фактический счёт OpenAI не доступен и не равен автоматически резерву.

Это подтверждает приём новой схемы и принятую сервером настоящую генерацию **в одном конкретном запросе**. На buyer-v7 такая же пара стабильно получала HTTP400 invalid_json_schema. Точный отвергнутый ключ старой схемы не установлен, поэтому этот успех не доказывает прежнюю гипотезу о конкретном keyword.

## Ручная проверка смысла

Свежий публичный JSON обеих моделей прочитан дополнительно без OpenAI. SHA256 совпали с сохранёнными источниками 22.10.2026. Подтверждены натуральная/искусственная замша, зимний и противоскользящий дизайн первой модели, описание широкой стопы, Western-декор и испанское происхождение второй.

**Полный зачёт фактической точности не поставлен:**

1. Бот написал `genuine sheepskin lining`, тогда как источник указывает `Dabīgā aitas vilna` — натуральную овечью шерсть. Источник не устанавливает материал с самой шкурой. Нужна более точная формулировка `sheep-wool lining`.
2. Бот написал `silver rivets`. Источник уточняет серебристый цвет заклёпок, не состав из драгоценного металла. Лучше `silver-coloured rivets`.

Первый пункт — неточность перевода материала; второй — двусмысленная потеря уточнения цвета. Эти наблюдения сохранены отдельно, исходный ответ не переписан. Серверные проверки не являются общим доказательством смысловой точности свободного текста.

Исходный отчёт скопирован без изменений в `2026-10-23-buyer-v8-smoke-live.json`, SHA256 `784075f1b2a9519de982008c5eba1086121990d3694b52a2ad14c0b03cd8ca4c`. План и ручной обзор сохранены рядом. Все пять предыдущих отчётов 50/v4/v5/v6/v7 проверены по прежним SHA256 и не изменены.

Изменений кода/Cloudflare/конфигураций/лимитов/секретов в этой итерации нет. Main и TrendScanner не затронуты. Новые автоматические тесты не запускались: выполнен только согласованный живой запрос и проверка JSON/UTF-8/хешей новых данных. Последние тесты реализации остаются 2351 Node + 27 workerd + 7 Python, их не следует представлять как повторно выполненные сегодня.

Текущий статус: ошибка формата не проявилась в этом английском запросе, генерация действительно принята. Общая готовность всех магазинов и языков пока не доказана; замечания к точности формулировок остаются открытыми. Продолжение RU/LV требует отдельного согласования двух новых запросов/резерва. В использованное разрешение на один запрос они не входят. Платные вызовы остановлены после первого.
