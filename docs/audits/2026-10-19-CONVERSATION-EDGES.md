# Единое обновление: контекст диалога и сложные формулировки

Подготовленный release `buyer-v4` включает предыдущие исправления `fidelity-v2`, `buyer-v3`, мобильное поле ввода и изменения ниже. Для установки нужен один полный SHA последней рабочей ветки, а не отдельные команды на каждое исправление. На Cloudflare ничего не опубликовано. На компьютере пользователя файлы не менялись.

## Воспроизведено и исправлено локально

| Случай | Было | Подготовленное поведение |
| --- | --- | --- |
| «Нет, я про первый», «не первый, а второй» | Ссылка на нужный товар терялась | Выбирается однозначно указанная положительная ссылка из исходного списка |
| «А у третьего…» | Парсер и внешняя ветка Worker не поддерживали третий вариант | Третья ссылка выбирается, если она действительно есть в списке |
| «Compare the first and third» | Не выбирались нужные два товара | Читаются именно два указанных товара; требуется полное сравнение обоих |
| First aid / second hand / third party | Слова могли ошибочно выбрать товар по порядку | Это не считается порядковым выбором |
| «Не нужен корм для котят, нужен взрослому коту» | Отрицание становилось положительным фильтром котят; поиск был пустым | Поддержанное отрицание исключает категорию котят, сохраняет корм и взрослое назначение |
| «Не сухой, а влажный корм для котят» | Одновременно требовались сухой и влажный | Сухой исключается, влажный/котята сохраняются. Canned-food адреса распознаются как корм, не как отсутствие категории |
| Доставка с товарной ссылкой, в том числе «доствка» | URL мог перехватить вопрос и вызвать чтение товарной страницы | Общие правила доставки имеют приоритет над товарной ссылкой и прежним размерным контекстом |
| «Ошибся, ему 8 месяцев» после «8 лет» | Новая короткая реплика не распознавалась как возраст младенца | Новое сообщение запускает безопасную проверку; старый возраст не подтверждает пригодность |
| «На упаковке написано другое» | Не было надёжного приоритета расхождения источников | Бот признаёт сообщённое расхождение, не считает прежний ответ подтверждённым, предлагает проверку магазина без выдуманной заявки |
| `dostavka`, `nuzhni zimnie botinki` | Нераспознанная политика/пустой каталог | Поддержаны ограниченные точные алиасы; названия моделей не переписываются |
| «Точно подойдёт», «will definitely fit», «доставят к пятнице» | Часть формулировок обходила существующий guard | Дополнительные неподтверждённые обещания отклоняются. Честный отказ гарантировать разрешён; оговорка перед «но точно доставят» не оправдывает последующее обещание |

Число слов «first» или «третий» не даёт доступа к произвольному адресу: ссылка берётся только из проверенного списка этого магазина, максимум из трёх вариантов. Сравнение читает не более двух страниц и использует не более одной попытки модели. Если нужного пункта нет или запрос неоднозначен, другой товар автоматически не подставляется.

Отрицания поддержаны для ограниченных явных категорий RU/LV/EN. Неизвестные модели, состав, аллергены и количественные условия не удаляются из поиска. По названиям нельзя обещать отсутствие курицы, безопасность, совместимость или пригодность. Полный смысл произвольной свободной речи этими правилами не доказан.

- `npm run test:worker`: 24/24, настоящий workerd/SQLite с подставным провайдером. Новый тест проверяет бесплатный поиск с отрицанием, приоритет доставки при URL, одно резервирование, конфликт источников и прежний общий лимит.
- Python runner: 7/7, без сетевых запросов. Версия `buyer-v4` учитывается при моделировании сохранения исходного списка выбора.
- Основной интерфейс и все пять клиентских артефактов собраны. Секреты, бюджеты, namespace `experiment-v1` и конфигурация развёртывания не менялись.
- Файлы интерфейса/CSS из мобильного исправления не изменены этой итерацией. Его 204 браузерных измерения и снимок сохранены в [отчёте по мобильной форме](mobile-composer-20261019/README.md).
- В этой итерации **0 живых chat-запросов и 0 платных обращений**. Подставные ответы провайдера проверяют обработку, а не реальную частоту ошибок OpenAI.
- Исходные 50 новых живых ответов от предыдущего аудита, старые `live-50` и резервные копии не переоценивались и не заменялись успехами.

Сценарии и ожидаемые исходы воспроизводятся в `test/conversation-edges.test.mjs`. Контроль хранения резервов в `test-runtime/conversation-edges.test.mjs`. Негативные проверки включают приватные данные вместе с исправлением выбора, попытку скрыть инструкцию в продолжении диалога, отсутствующий третий пункт, вымышленную модель и неподдержанное ограничение состава.

## Что ещё проверить после публикации

1. Получить `catalogRevision:buyer-v4` и правильное имя каждого демо из `/api/config`, без изменения лимитов.
2. Повторить целевые диалоги на обновлённых серверах: выбор1→3→сравнение1/3, отрицание назначения, исправление возраста, расхождение с упаковкой, доставка с опечаткой и URL, давление на ответ, завершение диалога.
3. Проверить источники и сохранение условий в самих ответах модели. Локальный тест с подставным провайдером не заменяет этот этап.
4. Отдельно проверить многосоставные вопросы о товаре и политике. Исправление гарантирует приоритет политики/индивидуального случая перед чтением URL; оно не обещает полный объединённый ответ по всем характеристикам и правилам за одну реплику.
5. Проверить широкие составные ограничения, транслит вне небольшого словаря, замену модели по названию, языковые формулировки вне тестового набора и поведение при403/недоступных характеристиках. Отсутствие надёжного ответа нельзя превращать в отсутствие товара у магазина.
6. Anete по-прежнему не проходил новую авторизованную живую серию. Ограничение чтения отдельных страниц HobbySet не снято.

Для целевого платного повтора нужен отдельный согласованный объём; текущие дополнительные 108 проверок были локальными. Публикация остаётся отдельным действием по прежней инструкции: подготовка по полному SHA через `prepare-live-audit-update.mjs`, затем согласованный publisher с receipt. Подготовка сама не публикует и не обращается к OpenAI. Не требуется устанавливать Python или Playwright на компьютере пользователя, чтобы выполнить штатное Node-обновление.
