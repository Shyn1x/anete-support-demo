# Ссылки на товары в сообщениях

**История предыдущего этапа.** После описанного ниже исправления добавлено чтение конкретных товарных карточек пяти магазинов: см. [текущее поведение и ограничения](CATALOG-READING.md). Указания ниже «страница не прочитана» и «чтение не реализовано» описывают прежнюю версию; они остаются применимы при отключённой функции или для неподдерживаемого Anete.

Исправление от 15.10.2026 после примера пользователя: «Размер 48.5 https://apavi40plus.com/ru/products/klasiskas-viriesu-kurpes-lloyd-dargun-10-054-59».

Прежняя защита считала любой URL попыткой изменить правила. Теперь публичная HTTPS-ссылка на проверенный домен выбранного магазина принимается как контекст. Ссылки другого магазина, стороннего домена, на аккаунт/оплату, с авторизационными параметрами, нестандартным портом или credentials получают отдельное понятное пояснение. Инструкции сменить правила и запросы секретов по-прежнему блокируются.

Параметры variant/utm и фрагменты удаляются из контекста маршрутизации. Цифровой артикул внутри URL не считается телефоном. Персональные данные за пределами URL продолжают блокироваться. Для выбора языка используется текст вопроса без URL. Публичный адрес страницы не добавляется к проверенным источникам автоматически.

Сервер не скачивает произвольные страницы и не следует редиректам. Поэтому это **приём ссылки**, а не интеграция полного каталога. Для уже подключённой товарной карточки точное совпадение адреса, включая языковой префикс, может определить модель. На неизвестную карточку бот не подставляет характеристики знакомой модели.

Для примера с размером 48.5 бот уточняет, интересует ли наличие или соответствие длине стопы, и сообщает, что страница автоматически не прочитана. Если предыдущая реплика была вопросом о размерной сетке, этот контекст сохраняется: повторно просить назвать модель не нужно. Пока таблица не подключена, бот не выдумывает длину стельки и не подтверждает остатки.

Публичная страница Lloyd Dargun открылась при ручной проверке через HTTP 200, но это не означает, что её содержимое загружается ботом во время разговора. Новых товарных фактов в базу в этом изменении не добавлено.

## Проверки

1080 / 1080 Node-тестов; 8 / 8 workerd-проверок; сборка и изоляция пяти сайтов пройдены. 45 новых тестов проверяют шесть доменов на RU/LV/EN, посторонние/частные ссылки, credentials, кодированные управляющие символы, цифровой variant, сохранение размерного контекста и отсутствие подстановки другого товара. Два прежних сценария внешних URL теперь ожидают специальный ответ link-unsupported вместо ответа об инструкциях/секретах; внешние страницы всё так же не открываются.

Платных обращений OpenAI при проверке: 0. Реальное чтение каталога и ответы по произвольной карточке ещё не реализованы. Это ограничение нельзя скрывать за количеством пройденных тестов.
