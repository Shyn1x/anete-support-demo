# Исправления после живой проверки каталогов

Ветка: `fix/catalog-answer-fidelity-20261018`. Серверная ревизия кандидата: **`fidelity-v2`**. Основа — опубликованный `86d96cdd2daf59c5e9884e21da857e7672311cd6` и отдельный неизменённый отчёт живой проверки `b3981286cc30b6e3c9991a6009f930a150e38f22`.

## Что изменено

### Bariba: искажение смысла при допустимом числе

В живом ответе «мясо птицы не менее 25%» стало «куриной грудкой около 25%». Старые проверки видели допустимое число и существующую цитату, но не выявили искажение.

Добавлены детерминированные проверки процентных величин: нижняя/верхняя граница, приблизительность и распознаваемый предмет характеристики. Процент мяса птицы нельзя перенести на куриный жир только потому, что он тоже упомянут в составе. Неподтверждённые конкретизации «грудка» и «филе» отклоняются. Причины сохраняются как `catalog_quantity_qualifier`, `catalog_quantity_binding`, `catalog_unsupported_detail`.

При отклонении генерации сервер может показать распознанные буквальные части состава на RU/LV/EN: мясо птицы «не менее», куриный жир, гидролизат куриной печени. Используется ограниченный набор точных формулировок под явным заголовком состава. Это не свободный перевод текста. Ответ явно сообщает, что это лишь часть состава; отсутствие распознанного ингредиента не означает его отсутствие в корме.

### Apavi: обрезанный контекст и неудобный резервный ответ

Вместо первых 12 строк выбираются относящиеся к вопросу строки из всего ограниченного прочитанного описания. Технические поля получают приоритет; значение после отдельного заголовка также включается. Лимит остаётся 12 полных строк / 2400 символов. Строки при отборе не обрезаются посередине.

Поля `Materiāls` и `Odere` из нижней части описания достигают модели. Для распознаваемых технических значений есть проверенные переводы. Общий «материал» не переименовывается автоматически в «верх» для произвольного товара. Смешанная подкладка «кожа / текстиль» не должна стать просто кожей: это дополнительно проверяется как `catalog_material_qualification`.

Точная цитата по-прежнему обязательна и проверяется по исходному тексту. В инструкциях запрошены короткие непрерывные выдержки без многоточий и перевода; условия принятия цитаты не ослаблены. Цитаты должны находиться в поле доказательств, а не загромождать ответ покупателю. Максимум вывода модели остаётся 450 токенов.

При отклонении ответа распознаваемые поля показываются на языке пользователя без рекламного абзаца из оригинала и без вопроса «какой вариант хотите разобрать», когда товар уже выбран. Неизвестные значения не переводятся догадкой; пользователь получает понятное сообщение о невозможности подтвердить все детали и ссылку на источник.

### HobbySet: ограниченный запасной источник при HTTP 403

**Причина отказа магазина в чтении не устранена.** Обхода защиты, смены User-Agent на имитацию покупателя, скрытых API или авторизации магазина не добавлено.

Для одного набора акварели сохранено вручную проверенное публичное название, из которого известно число цветов — 12. Источник:

`https://hobbyset.lv/products/lv/2372/150958/sort/1/filter/0_0_0_0/Akvare%C4%BCkr%C4%81su-komplekts-12-kr%C4%81sas.html`

Проверено **2026-10-18T16:04:30.397Z** во время отдельной сверки источников предыдущего аудита. Текст описания, товары других магазинов, цены и остатки в запасную запись не включены. Запись действует семь суток, до **2026-10-25T16:04:30.397Z**, без автоматического продления.

Она используется только для точного товара своего магазина при явном HTTP 403. Не используется при 404, редиректе, неизвестном товаре, до даты проверки или после истечения срока. В ответе видна дата и отказ текущего чтения; `productRead:false`, `catalogSnapshot:true`, причина HTTP 403 сохраняется. Состав не утверждается. Наличие и цены не подтверждаются. Для запасной записи генерация и денежный резерв запрещены даже при включённом ИИ. Для прочих недоступных товаров остаётся отказ чтения.

Это частичное улучшение конкретного ответа, **не восстановление доступа к полному каталогу HobbySet**. Для надёжных ответов по другим описаниям нужен разрешённый источник или согласованная выгрузка магазина.

## Отдельно о старой серии 50

При проверке совместимости обнаружено: старый оценщик ожидает фиксированные `cardIds` и `mode:ai`, а каталог возвращает `mode:catalog` и товарные источники. Одинаковый `context-v2` сам по себе не делает этот оценщик совместимым.

Добавлена остановка старого runner/retest до запросов чата, если сервер объявляет каталоговую ревизию. Результаты 27/50 не мигрируются и не переоцениваются. **Старую серию пока не продолжать этим оценщиком.** Нужна отдельная адаптация оценки товарных случаев с сохранением исходных результатов и отдельным согласованием платных повторов. Офлайн-аудит прежнего отчёта остаётся доступен.
