# Natural conversation endings — 18 October 2026

## Confirmed regression

The recording shows the Lomenti studio assistant responding to
`Thank you! Have a nice day.` with a new sales question. The studio preflight
recognised only isolated courtesy words, while the existing shared shop router
already understood combinations. The unmatched studio message reached the model
with an unconditional instruction to ask a project question.

## Changes

- Studio preflight now reuses the whole-message courtesy parser for gratitude,
  farewell and combined closings. These return brief localised replies without a
  provider call or API reservation, after the same signature, nonce and rate checks.
- The exact recorded English closing returns `You’re welcome! Have a lovely day
  too 🙂`, also after Latvian history. RU and LV equivalents are covered.
- The model instruction requests a follow-up only if information is actually
  missing. It explicitly gives substantive questions priority over courtesy and
  forbids sales prompts on a closing.
- Added common English/Russian/Latvian farewell variants to the shared router.
  It still consumes every token, so a thank-you cannot hide an unresolved issue.
  Shop gratitude/farewell replies no longer append service reminders.
- No persistent ended flag: a new user question resumes normal help immediately.
- Fact/number/source validation, privacy checks, tenant boundaries and budget
  identifiers/caps are unchanged.

## Validation

- `npm test`: 1,571 passed, including 52 added regression cases.
- `npm run build:clients`: six shop asset bundles built successfully.
- `npm run test:worker`: 19 passed. A new actual-workerd/SQLite test verifies
  multilingual closings, zero outbound requests/reserve, normal resumption with
  one mock provider call, closing at exhausted reserve, and nonce replay rejection.
- Tests cover the exact recording, informal thanks, RU/LV/EN combinations,
  thanks + new question, farewell + new question, later resumption, budget caps,
  preserved mandatory handoff for actual complaints, and existing validation.
- All provider responses in tests are synthetic. No paid OpenAI request, company
  message, counter reset or live publication was performed.

## Publication

This release includes the earlier collapsible contact panel and Lomenti branding.
Use the existing immutable-release ZIP updater, then its receipt with
`publish-live-audit.mjs --receipt RECEIPT_PATH --confirm-publish` to update all six
existing Workers. Do not use `--owner-only`: shared shop courtesy replies changed
as well. The Lomenti website already calls the owner's signed studio route, so
this backend fix does not require a new Sites frontend deployment.

Existing reports, passwords, runtime flags, budget settings and Durable Object
bindings are preserved by the reviewed preparation/publication scripts. No live
model test is authorised by this release. Production behaviour changes only after
explicit publication by the owner.
