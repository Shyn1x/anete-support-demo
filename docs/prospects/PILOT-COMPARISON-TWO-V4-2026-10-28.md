## Ограничения

- Дополнительный запуск согласуется владельцем отдельно: точные аргументы `--run --allow-paid --max-requests 2`. В предоставляемом PowerShell-блоке до этого вызова — явный `Read-Host`, требуется `YES` для двух запросов с внутренним резервом максимум $0.02. «Окей» на предыдущем шаге не используется для скрытого запуска. При подготовке не было настоящих chat POST или платных вызовов.
- Исходный отчёт трёх проверок должен побайтно совпасть с SHA-256 `1118354df640d084ad9f04dddeacfcef4a1d246745c7abbb7230a45c560275b8`. Отдельная неизменённая копия без секретов включена в fixture для бесплатных тестов файлового цикла.
- Точный план закреплён SHA-256 `3b3910456af84369ebe11bb9a8a7fe81950cf5196140b7623ab3799945a377d5`. Расширенный/изменённый план отклоняется до сети.
- Проверяются квитанция `pilot-code-update-evidence-v4.json`, публичные v4-конфигурации двух магазинов, прежний резерв 10000 microUSD на вызов, закрытый доступ и прежние context-v2 / buyer-v8.
- Все пять записей приватных паролей проверяются на формат/уникальность, вход осуществляется только в Dzijas и JIG. Пароли, cookies, заголовки и API-ключи не входят в отчёт.
- Общая `.live-50.lock` исключает параллельный прогон. Новая постоянная локальная `.pilot-comparison-2-v4.json` с `wx` исключает повтор из другого ZIP или TEMP. Это нефинансовая отметка согласованного контроля после исправления кода, не новый серверный финансовый идентификатор.
- Новый отчёт: `pilot-comparison-2-<timestamp>.json`, schema `pilot-comparison-2-v1`, в прежней приватной папке партии. Старые 50/15/3 отчёты, их отметки и квитанции обновлений открываются только для чтения и сверяются по хешам после завершения.
- Перед каждым POST — pending/checkpoint; пауза 7 секунд; максимум два POST. Сетевой неопределённый исход, HTTP/JSON или бюджетный отказ останавливают проверку без повторов. При отказе сохранить отчёт/отметки, не удалять их и не запускать заново вслепую.
- Fallback остаётся REVIEW. Наблюдавшееся рекламное утверждение качества отдельно помечается REVIEW, даже если сервер его пропустит. Каждый ответ требует ручного чтения; автоматическая оценка не является гарантией фактической точности.
