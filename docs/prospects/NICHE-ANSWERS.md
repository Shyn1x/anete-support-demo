Источники и дата проверки указаны в `src/niche-data.js`. Все ответы показывают название конкретной модели. Нельзя переносить эти факты на остальные товары. Текущие цены, остатки и партии не сохранены и не подключены.

Узкие понятные вопросы обслуживаются бесплатно по проверенным карточкам, даже если включён AI. Лимиты количества сообщений продолжают действовать. Неизвестная модель вызывает уточнение; запрос наличия, цены или срока годности — объяснение отсутствия текущих данных. Выбор AI не может открыть нишевую карточку без соответствующего запроса. Индивидуальные медицинские вопросы и обещания безопасности не решаются товарной карточкой.

Это ограниченный первый маршрутизатор, а не универсальный поиск каталога. Для новых моделей и сложных перефразировок нужны следующие проверенные карточки и тесты. Полный артикул обуви из длинной последовательности цифр может блокироваться существующей защитой персональных данных; для демо используйте короткий код 42801. Старый блок быстрых вопросов пока сохранён.

## Anete

Новых товарных карточек не добавляли: повторное открытие сайта завершается тайм-аутом / страницей блокировки Cloudflare. Не обходили защиту и не связывались с компанией. Для продолжения достаточно публичных страниц, сохранённых пользователем в PDF, включая URL и дату. Не нужны учётные данные, cookies или клиентские заказы. Противоречия и неполные описания требуют дополнительной проверки.

## Публикация

Код сохранён в GitHub. Основной Worker получает изменения через существующую сборку репозитория; пять отдельных Workers обновляются из уже авторизованного проекта на компьютере владельца. Здесь авторизованной сессии Cloudflare CLI нет; публикация пяти сайтов не подтверждается этим отчётом.

Из прежней папки проекта загрузите `scripts/update-niche-answers.mjs` из проверенного коммита, затем выполните `node scripts/update-niche-answers.mjs <SHA>`. Скрипт скачивает пять файлов исходного кода, собирает пять изолированных демо и обновляет существующие Workers. Секреты не читает и не меняет; новые пароли и API-ключ не нужны. Счётчики и пределы бюджета сохраняются. Новые платные вызовы OpenAI при разработке не выполнялись.
